# Buggies For Sale Australia (buggiesforsale.com.au)

Australia's premier online store for off-road buggies, 4x4 UTVs, electric and remote golf carts, youth go-karts, parts, and accessories.

## Features
- **Desert Race Editorial Theme**: Warm desert dune bone (`#F4F1EA`), industrial charcoal (`#1A1A1A`), dust tan (`#D4A373`), and high-impact safety orange (`#E65F2B`).
- **Complete Niche Architecture**:
  - Off-Road & Recreational Buggies (SSVs, UTVs, Dune Buggies, Go-Karts, Youth Buggies, Silent 72V Electric Trail Buggies)
  - Golf Buggies & Carts (Remote Control, Motorised Lithium, Push/Pull, Ride-On Luxury)
  - Brand Hub (Polaris, MGI Golf, Club Car, Motocaddy, Can-Am, Segway, CFMOTO)
  - Parts & Accessories (Lithium batteries, Winches, All-Terrain tyres, Filters)
  - Clearance / Sale
- **High-Converting E-Commerce Engine**:
  - Live filterable catalog with price slider, keyword search, in-stock toggle, and sort
  - Cart drawer with live free shipping progress bar towards $1,000 threshold
  - Minimum order ($250) validation
  - 5% instant checkout discount for BTC / USDT cryptocurrency
  - Australia Postcode delivery freight estimator
  - Interactive multi-channel chat (WhatsApp, SMS Text, Phone, Email)
  - 10 comprehensive SEO buying guides
- **2026 AI & Agent Readiness**:
  - Model Context Protocol (MCP) Streamable HTTP Server (`/api/mcp`)
  - Universal Commerce Protocol (`/.well-known/ucp`)
  - Agent Communication Protocol (`/.well-known/acp.json`)
  - RFC 9727 API Catalog (`/.well-known/api-catalog`)
  - Agent Skills Index (`/.well-known/agent-skills/index.json`)
  - WebMCP browser provider (`/js/webmcp.js`)
  - Complete JSON-LD schema markup (Store, Organization, Product, Offer, BreadcrumbList, FAQPage, SearchAction)

## Deployment Instructions

### Local Development
```bash
npm install
npm run dev
```

```bash
node scripts/crosscheck.mjs
```

### Build

```bash
npm run build
```

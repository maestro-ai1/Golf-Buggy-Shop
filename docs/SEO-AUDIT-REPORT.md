## 2. Keyword method and sources

- **Keyword bank:** all-keywords-kd28-and-below (15,835 rows), the live Semrush pulls dated 2026-10-18, the competitor gap file (95 rows) and the unmapped transactional and commercial file (513 rows).
- **Golden rules applied:** one primary and five unique secondaries per page, nothing already mapped elsewhere, primary in title, H1, meta and first 160 words, density under 1.3%, no stuffing, secondaries woven into natural sentences.
- **Google check:** the live results for "golf buggies for sale Australia" and "golf carts for sale near me" are mostly retailer pages, old reviews and marketplace listings, so a well-structured category page with FAQ schema is a realistic win.
- **Semrush through Noxtools:** the Noxtools Semrush mirror (2.semrush.com.in) was blocked by the permission system in this session, so it was not opened and nothing was worked around. To use live Semrush data, open the Semrush server in your own Chrome and I can read the screen, or paste an export and I will merge it.
